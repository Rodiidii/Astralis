Les vidéos locales assemblent un aperçu officiel animé du talent et une réplique
officielle anglaise de l’ultime. Elles ne contiennent pas la bande sonore complète
d’une capture de combat. Les deux fichiers d’origine et la page HoYoWiki de chaque
personnage sont indiqués dans `manifest.json`.

Pour Phainon, seule la réplique est disponible dans ces données : elle accompagne
sa scène Astralis. Les personnages du lore utilisent une scène Astralis et un
lecteur renvoyant à leur apparition officielle ; ces pouvoirs sont propres au
tycoon. Une vidéo personnelle peut remplacer le média intégré pour tout personnage.

Les fichiers sont prêts à lire dans l’application. Pour les reconstruire :
`python scripts/build-express-ultimate-media.py` (Python et imageio-ffmpeg).
