Un accueil cinématique personnalisable, une Arcade illustrée avec Genshin Idle et un Express des Mondes plus vivant.

- Nouveau tableau de bord : paysages de Teyvat, personnage, effets, animations réglables et panneaux utiles réorganisables.
- Arcade : seize destinations avec des images Genshin et le retour de Genshin Idle, avec sa sauvegarde indépendante.
- Tycoon : trois ambiances pour le comptoir et des fêtes régionales dont les bonus modifient réellement le jeu.
- Navigation : suppression des bordures, réglages de disposition et correction de l’espace au-dessus du contenu.
- CalcSheets : « Mes compositions » défile avec la page.
- Correction du chargement du moteur complet de calcul dans le navigateur.

Validation : 55 tests de logique, 6 tests du paquet web et parcours de navigateur sur ordinateur et téléphone. Les essais ont été exécutés dans des sessions séparées, sans modifier le compte utilisateur.

**Application Windows :** télécharger `Astralis-Update.zip`. Son empreinte SHA-256 est fournie à côté.

**InfinityFree :** extraire `Astralis-InfinityFree.zip`, puis envoyer le contenu de `htdocs` par FTP dans le dossier `htdocs` du domaine, avec `.htaccess`. La notice précise la configuration facultative du serveur de données pour les flux en direct. Les opérations Windows restent réservées à l’application installée. Aucun transfert vers un compte InfinityFree n’a été effectué.

Les profils, les brouillons privés, les caches et les diagnostics ne sont pas inclus dans les archives.
